ARQUITETURA DE PROMPTS - AGENTEGO

O "cérebro" do agente é composto por três níveis hierárquicos de personalização:

===============================================================================
NÍVEL 1: ESTRUTURA CORE (SISTEMA)
===============================================================================
- Onde fica: bot-service/app/agent.py (função montar_prompt)
- Finalidade: Define as regras de comportamento universal e lógica técnica.
- O que controla:
    * Regras de ouro (não inventar dados, empatia).
    * Fluxo de transbordo humano (detecção de tags [SUGERIR_TRANSBORDO], etc).
    * Integração de contexto dinâmico (Horário, Intenção, Estágio no Funil).
    * Estrutura visual da resposta (uso de emojis, objetividade).
- Quando alterar: Quando precisar mudar a LOGICA de funcionamento de todos os robôs.

===============================================================================
NÍVEL 2: TEMPLATE DE NICHO (ESPECIALIDADE)
===============================================================================
- Onde fica: Banco de Dados (tabela prompt_templates) / Painel Admin.
- Finalidade: Define o "DNA" básico de cada indústria (Academia, Contabilidade, etc).
- O que controla:
    * Missão base do nicho.
    * Tom de voz padrão (ex: Motivador para Academias).
    * Placeholders universais (ex: [NOME_DA_ACADEMIA]).
- Quando alterar: Quando quiser melhorar o atendimento para UM SETOR INTEIRO (ex: todas as academias).

===============================================================================
NÍVEL 3: AGENT BUILDER (CUSTOMIZAÇÃO DO CLIENTE)
===============================================================================
- Onde fica: Dashboard do Cliente -> Menu Configurações.
- Finalidade: Personalização específica da unidade do cliente.
- O que controla:
    * Nome da IA, Nome da Empresa.
    * Base de Conhecimento (Planos, Horários, Professores, Serviços).
    * Instruções Adicionais (Regras específicas daquela unidade).
    * Telefones de contato e links.
- Quando alterar: No dia a dia, para ajustes finos de uma empresa específica.

===============================================================================
HIERARQUIA DE PRIORIDADE
===============================================================================
O sistema sempre tenta priorizar os dados do AGENT BUILDER (Nível 3).
Exemplo: Se o Template de Nicho diz que o nome da IA é "Assistente", mas o cliente definiu como "Rosana" no Dashboard, o robô se apresentará como "Rosana".

--------------------------------------

- Multi-tenant simples: coluna empresa_id em todas as tabelas
- Um container para bot-service (FastAPI), um para o banco, um para o dashboard
- Banco de dados: migrar de SQLite para PostgreSQL (sem perder dados atuais)
- Histórico em RAM mantido no MVP — Redis é Fase 2
- Buffer de mensagens: debounce de 3 segundos (já implementado)
- Contexto de tempo real: já implementado
- Transbordo: já implementado (aguardando confirmação + pausa do robô)

[1.4] Criar classifier.py (classificação de intenção)
  def classificar_intencao(texto):
      texto = texto.lower()
      if any(p in texto for p in ["preço", "valor", "quanto", "custa", "mensalidade"]):
          return "preco"
      if any(p in texto for p in ["horário", "hora", "abre", "fecha", "funciona"]):
          return "horario"
      if any(p in texto for p in ["aula", "spinning", "zumba", "funcional"]):
          return "aulas"
      if any(p in texto for p in ["visitar", "conhecer", "ir", "vir", "aparecer"]):
          return "visita"
      if any(p in texto for p in ["plano", "modalidade", "contrato"]):
          return "plano"
      return "duvida"

[1.5] Lógica de stage (funil de vendas)
  def calcular_stage(stage_atual, intencao):
      progressao = {
          "novo": {
              "preco": "curioso",
              "horario": "curioso",
              "aulas": "curioso",
          },
          "curioso": {
              "visita": "interessado",
              "plano": "interessado",
          },
          "interessado": {
              # stage avança para "agendado" só quando aceitar visita explicitamente
          }
      }
      return progressao.get(stage_atual, {}).get(intencao, stage_atual)

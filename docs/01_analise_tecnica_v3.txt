ITEM 1.1 — docker-compose com fallbacks inseguros (CRÍTICO)
---
ARQUIVO: docker-compose.yml

CÓDIGO ATUAL:
  POSTGRES_USER: ${POSTGRES_USER:-user}
  POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-pass}
  DATABASE_URL=postgresql://${POSTGRES_USER:-user}:${POSTGRES_PASSWORD:-pass}@...
  command: redis-server --requirepass ${REDIS_PASSWORD:-mudar_senha_redis}

O operador :-valor define um fallback que é usado se a variável
não existir no .env. Em produção, se o .env não for carregado
corretamente (ex: deploy com problema), o sistema sobe com
credenciais públicas silenciosamente.

CORREÇÃO:
  Remover todos os fallbacks :-valor do docker-compose:
    POSTGRES_USER: ${POSTGRES_USER}
    POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    POSTGRES_DB: ${POSTGRES_DB}
    command: redis-server --requirepass ${REDIS_PASSWORD}

  Se a variável não existir, o Docker Compose falha com erro claro
  em vez de subir com credencial fraca.

ITEM 2.1 — Impersonation grava JWT no localStorage do admin
---
ARQUIVO: dashboard/src/app/(admin)/admin/page.tsx

Conforme identificado na v2: o handleImpersonate faz
localStorage.setItem("atendia_token", access_token), gravando
o token de um cliente no navegador do admin. Se o admin tiver
outra aba do dashboard aberta, há risco de conflito de sessão.

CORREÇÃO:
  Ao invés de gravar no localStorage, abrir a URL com o token
  como parâmetro temporário e ler/limpar no carregamento:

  No admin (handleImpersonate):
    const url = `/${slug}?_imp=${access_token}`;
    window.open(url, "_blank");

  No layout do dashboard (layout.tsx), ao carregar:
    const params = new URLSearchParams(window.location.search);
    const impToken = params.get("_imp");
    if (impToken) {
      localStorage.setItem("atendia_token", impToken);
      // Limpar da URL sem reload
      window.history.replaceState({}, "", window.location.pathname);
    }

PARTE 2 — SEGURANÇA DE DADOS (resposta à pergunta do cliente)
================================================================

PERGUNTA: "Os dados ficam seguros? Vale criptografar?"

RESPOSTA DIRETA: Para o estágio atual do produto, NÃO é necessário
criptografar os dados em repouso no banco. Veja o porquê e o que
comunicar ao cliente:

O QUE JÁ PROTEGE OS DADOS HOJE:
  1. PostgreSQL acessível APENAS via rede interna Docker
     (porta 5432 em 127.0.0.1 — não acessível pela internet)
  2. Senhas de usuários em bcrypt (hash irreversível)
  3. JWT para autenticação (token expira, não é senha)
  4. Dados hospedados em VPS próprio (Contabo, Brasil)
     → não passam por AWS, Google ou Microsoft
  5. Evolution API: mensagens transitam pelo WhatsApp (criptografia
     end-to-end nativa do próprio WhatsApp)
  6. LGPD: política de privacidade + aceite explícito (a implementar)

POR QUE NÃO CRIPTOGRAFAR O BANCO AGORA:
  Criptografia de campos no banco (ex: pgcrypto) traz custos altos:
  - Não é possível fazer WHERE telefone = '55119...' diretamente
  - Cada leitura exige descriptografia na aplicação
  - Queries de relatório (funil, insights) ficam muito complexas
  - Debug direto no banco fica inviável
  - Aumenta a superfície de bugs sem benefício proporcional

  Isso faz sentido para: healthtechs, fintechs, apps com CPF/RG.
  Para um sistema de atendimento via WhatsApp com nome e telefone,
  o nível de proteção atual é adequado e dentro das boas práticas
  do mercado SaaS brasileiro.

O QUE COMUNICAR AO CLIENTE (texto pronto para usar):

  "Seus dados ficam armazenados em servidor próprio localizado no
   Brasil, sem compartilhamento com terceiros. O acesso ao banco
   de dados é restrito e protegido por senha — ele não é acessível
   pela internet, apenas internamente pelo sistema. As senhas dos
   usuários são criptografadas e não são conhecidas nem por nós.
   As conversas transitam pelo próprio WhatsApp, que usa criptografia
   de ponta a ponta. Seguimos as diretrizes da LGPD (Lei 13.709/2018)."

O QUE VOCÊ PODE ADICIONAR SEM CUSTO ALTO (recomendado):
  - Criptografar o campo config JSONB se ele contiver chaves de API
    do cliente (ex: chave OpenAI própria no futuro)
  - Usar HTTPS em todos os endpoints (já garantido pelo Easypanel)
  - Manter backups criptografados do PostgreSQL (pg_dump + gpg)

ITEM 3.2 — Endpoint de importação CSV
---
ARQUIVO: bot-service/app/dashboard_api.py

  from fastapi import UploadFile, File
  import csv
  import io

  @router.post("/membros/importar-csv")
  async def importar_membros_csv(
      file: UploadFile = File(...),
      empresa: Empresa = Depends(obter_empresa),
      db: Session = Depends(get_db)
  ):
      if not file.filename.endswith(".csv"):
          raise HTTPException(status_code=400, detail="Apenas arquivos .csv são aceitos")

      conteudo = await file.read()
      texto = conteudo.decode("utf-8-sig")  # utf-8-sig lida com BOM do Excel
      reader = csv.DictReader(io.StringIO(texto))

      importados = 0
      erros = []

      for i, row in enumerate(reader):
          try:
              # Aceita variações de nome de coluna
              nome = row.get("nome") or row.get("Nome") or row.get("NOME")
              telefone_raw = row.get("celular") or row.get("telefone") or \
                             row.get("Celular") or row.get("Telefone")
              vencimento_raw = row.get("vencimento") or row.get("data_vencimento") or \
                               row.get("Vencimento") or row.get("Data Vencimento")
              plano = row.get("plano") or row.get("Plano") or None

              if not nome or not telefone_raw or not vencimento_raw:
                  erros.append(f"Linha {i+2}: campos obrigatórios ausentes")
                  continue

              # Normalizar telefone: remover tudo que não é dígito
              telefone = "".join(filter(str.isdigit, telefone_raw))
              if len(telefone) == 11:  # DDD + 9 dígitos sem código do país
                  telefone = "55" + telefone
              if len(telefone) not in [12, 13]:
                  erros.append(f"Linha {i+2}: telefone inválido ({telefone_raw})")
                  continue

              # Parsear data (aceita DD/MM/YYYY e YYYY-MM-DD)
              from dateutil import parser as dateparser
              data_venc = dateparser.parse(vencimento_raw, dayfirst=True)
              if not data_venc:
                  erros.append(f"Linha {i+2}: data inválida ({vencimento_raw})")
                  continue

              # Upsert: se já existe pelo telefone, atualiza. Senão, cria.
              from app.database import MembroAcademia
              membro = db.query(MembroAcademia).filter(
                  MembroAcademia.empresa_id == empresa.id,
                  MembroAcademia.telefone == telefone
              ).first()

              if membro:
                  membro.nome = nome
                  membro.data_vencimento = data_venc
                  membro.plano_nome = plano
                  membro.ativo = True
                  # Reset dos flags de aviso se a data mudou
                  membro.aviso_7_dias_enviado = False
                  membro.aviso_3_dias_enviado = False
                  membro.aviso_vencido_enviado = False
                  membro.atualizado_em = datetime.utcnow()
              else:
                  novo = MembroAcademia(
                      empresa_id=empresa.id,
                      nome=nome,
                      telefone=telefone,
                      data_vencimento=data_venc,
                      plano_nome=plano
                  )
                  db.add(novo)
                  importados += 1

          except Exception as e:
              erros.append(f"Linha {i+2}: erro inesperado ({str(e)})")

      db.commit()
      return {
          "status": "ok",
          "importados": importados,
          "erros": erros,
          "total_linhas": i + 1 if 'i' in dir() else 0
      }

  # Adicionar ao requirements.txt:
  #   python-dateutil
  #   python-multipart  (necessário para UploadFile no FastAPI)

ARQUIVO: bot-service/app/dashboard_api.py

  @router.get("/membros")
  def listar_membros(
      empresa: Empresa = Depends(obter_empresa),
      db: Session = Depends(get_db)
  ):
      from app.database import MembroAcademia
      membros = db.query(MembroAcademia).filter(
          MembroAcademia.empresa_id == empresa.id
      ).order_by(MembroAcademia.data_vencimento.asc()).all()

      agora = datetime.utcnow()
      resultado = []
      for m in membros:
          dias_restantes = (m.data_vencimento - agora).days
          resultado.append({
              "id": str(m.id),
              "nome": m.nome,
              "telefone": m.telefone,
              "plano_nome": m.plano_nome,
              "data_vencimento": m.data_vencimento.strftime("%d/%m/%Y"),
              "dias_restantes": dias_restantes,
              "status": "vencido" if dias_restantes < 0
                        else "vencendo" if dias_restantes <= 7
                        else "ativo"
          })
      return resultado

  @router.delete("/membros/{membro_id}")
  def remover_membro(
      membro_id: uuid.UUID,
      empresa: Empresa = Depends(obter_empresa),
      db: Session = Depends(get_db)
  ):
      from app.database import MembroAcademia
      membro = db.query(MembroAcademia).filter(
          MembroAcademia.id == membro_id,
          MembroAcademia.empresa_id == empresa.id
      ).first()
      if not membro:
          raise HTTPException(status_code=404, detail="Membro não encontrado")
      db.delete(membro)
      db.commit()
      return {"status": "ok"}

  async def tarefa_avisos_vencimento():
      """Roda diariamente às 09:00 e envia avisos de vencimento de plano."""
      logger.info("Iniciando tarefa de avisos de vencimento...")
      db = SessionLocal()
      try:
          from app.database import MembroAcademia
          from app.whatsapp import enviar_whatsapp
          agora = datetime.utcnow()

          # Buscar empresas com membros (academias)
          membros_alertar = db.query(MembroAcademia).filter(
              MembroAcademia.ativo == True
          ).all()

          for membro in membros_alertar:
              dias = (membro.data_vencimento - agora).days
              empresa = db.query(Empresa).filter(
                  Empresa.id == membro.empresa_id,
                  Empresa.ativo == True
              ).first()
              if not empresa:
                  continue

              config = empresa.configuracoes.config if empresa.configuracoes else {}
              nome_empresa = config.get("nome_empresa", empresa.nome)
              nome_agente = config.get("nome_agente", "Assistente")

              mensagem = None

              if dias == 7 and not membro.aviso_7_dias_enviado:
                  mensagem = (
                      f"Olá, *{membro.nome}*! 👋\n\n"
                      f"Aqui é o(a) {nome_agente} da *{nome_empresa}*.\n\n"
                      f"Passando para lembrar que seu plano "
                      f"*{membro.plano_nome or 'atual'}* vence em "
                      f"*7 dias* (dia {membro.data_vencimento.strftime('%d/%m/%Y')}).\n\n"
                      f"Para renovar ou tirar dúvidas, é só falar aqui! 😊"
                  )
                  membro.aviso_7_dias_enviado = True

              elif dias == 3 and not membro.aviso_3_dias_enviado:
                  mensagem = (
                      f"Olá, *{membro.nome}*! ⚠️\n\n"
                      f"Seu plano *{membro.plano_nome or 'atual'}* na "
                      f"*{nome_empresa}* vence em *3 dias* "
                      f"(dia {membro.data_vencimento.strftime('%d/%m/%Y')}).\n\n"
                      f"Não deixe sua matrícula vencer! Renove agora e "
                      f"continue treinando. 💪"
                  )
                  membro.aviso_3_dias_enviado = True

              elif dias < 0 and not membro.aviso_vencido_enviado:
                  mensagem = (
                      f"Olá, *{membro.nome}*! 😊\n\n"
                      f"Seu plano na *{nome_empresa}* venceu em "
                      f"{membro.data_vencimento.strftime('%d/%m/%Y')}.\n\n"
                      f"Sentimos sua falta! Fale com a gente para renovar "
                      f"e voltar a treinar. 🏋️"
                  )
                  membro.aviso_vencido_enviado = True

              if mensagem:
                  try:
                      enviar_whatsapp(membro.telefone, mensagem, empresa.evolution_instance)
                      logger.info(f"Aviso enviado para {membro.nome} ({membro.telefone})")
                  except Exception as e:
                      logger.error(f"Falha ao enviar aviso para {membro.telefone}: {e}")

          db.commit()
      except Exception as e:
          logger.error(f"Erro na tarefa de avisos: {e}")
      finally:
          db.close()

  # Registrar no scheduler (em on_startup):
  scheduler.add_job(tarefa_avisos_vencimento, 'cron', hour=9, minute=0)

  async def tarefa_avisos_obrigacoes():
      """Avisa o proprietário do escritório sobre obrigações nos próximos 3 dias."""
      db = SessionLocal()
      try:
          from app.database import ObrigacaoFiscal
          from app.whatsapp import enviar_whatsapp
          agora = datetime.utcnow()
          em_3_dias = agora + timedelta(days=3)

          obrigacoes = db.query(ObrigacaoFiscal).filter(
              ObrigacaoFiscal.prazo <= em_3_dias,
              ObrigacaoFiscal.prazo >= agora,
              ObrigacaoFiscal.status == "pendente",
              ObrigacaoFiscal.aviso_enviado == False
          ).all()

          for ob in obrigacoes:
              empresa = db.query(Empresa).filter(
                  Empresa.id == ob.empresa_id,
                  Empresa.ativo == True,
                  Empresa.telefone_proprietario.isnot(None)
              ).first()
              if not empresa:
                  continue

              dias = (ob.prazo - agora).days
              msg = (
                  f"⚠️ *Lembrete de Obrigação Fiscal*\n\n"
                  f"*{ob.titulo}*\n"
                  f"Prazo: *{ob.prazo.strftime('%d/%m/%Y')}* "
                  f"({'hoje' if dias == 0 else f'em {dias} dia(s)'})\n\n"
                  f"{ob.descricao or ''}"
              )
              enviar_whatsapp(empresa.telefone_proprietario, msg, empresa.evolution_instance)
              ob.aviso_enviado = True

          db.commit()
      finally:
          db.close()

  scheduler.add_job(tarefa_avisos_obrigacoes, 'cron', hour=8, minute=0)

ITEM 5.4 — Página de Comunicados (nicho academia)

  @router.post("/comunicados/enviar")
  async def enviar_comunicado(
      payload: dict,
      empresa: Empresa = Depends(obter_empresa),
      db: Session = Depends(get_db)
  ):
      from app.database import MembroAcademia
      from app.whatsapp import enviar_whatsapp

      texto = payload.get("texto")
      url_imagem = payload.get("url_imagem")  # URL pública da imagem
      destinatarios = payload.get("destinatarios", "todos")
        -- "todos" | "vencendo" | "vencidos" | lista de IDs

      membros_query = db.query(MembroAcademia).filter(
          MembroAcademia.empresa_id == empresa.id,
          MembroAcademia.ativo == True
      )

      agora = datetime.utcnow()
      if destinatarios == "vencendo":
          em_7 = agora + timedelta(days=7)
          membros_query = membros_query.filter(
              MembroAcademia.data_vencimento <= em_7,
              MembroAcademia.data_vencimento >= agora
          )
      elif destinatarios == "vencidos":
          membros_query = membros_query.filter(
              MembroAcademia.data_vencimento < agora
          )

      membros = membros_query.all()
      enviados = 0

      for membro in membros:
          try:
              if url_imagem:
                  # Usar endpoint de envio de mídia da Evolution
                  from app.whatsapp_service import enviar_imagem
                  enviar_imagem(membro.telefone, url_imagem, texto, empresa.evolution_instance)
              else:
                  enviar_whatsapp(membro.telefone, texto, empresa.evolution_instance)
              enviados += 1
              import asyncio
              await asyncio.sleep(1.5)  # delay entre envios para evitar ban
          except Exception as e:
              logger.error(f"Erro ao enviar comunicado para {membro.telefone}: {e}")

      return {"status": "ok", "enviados": enviados, "total": len(membros)}
